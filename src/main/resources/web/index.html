Join in three steps

  1. Open Minecraft

    Launch Java Edition with a recent version and pick Multiplayer.

  2. Add the server

    Choose Add Server and paste play.example.com as the address.

  3. Hop in

    Select the server, press Join, and say hi in chat below.
